# Aurora HomeScreen 2035

Eine originale, futuristische Gaming-Console-HomeScreen-Web-App – inspiriert von modernen Konsolen-Dashboards, aber komplett neu gestaltet.

## Features

- Premium Dark UI mit Glassmorphism und Neon-Licht
- Schwebende, fiktive Game-Cards
- Dynamischer Featured-Bereich
- 3D-Hover-Effekte
- Tastatursteuerung mit Pfeiltasten
- Live-Uhr
- Responsive Layout für Desktop und kleinere Screens
- Keine echten PlayStation-, Sony- oder Game-Marken

## Dateien

```text
index.html   # Struktur der App
styles.css   # komplettes futuristisches UI-Design
app.js       # Interaktionen, Uhr, Card-Auswahl, 3D-Hover
```

## Lokal starten

Einfach `index.html` im Browser öffnen.

Alternativ mit einem lokalen Server:

```bash
python3 -m http.server 5173
```

Danach im Browser öffnen:

```text
http://localhost:5173
```

## GitHub Pages

Das Projekt ist statisch und kann direkt über GitHub Pages veröffentlicht werden:

1. Repository öffnen
2. Settings → Pages
3. Source: `Deploy from a branch`
4. Branch: `main`, Folder: `/root`
5. Speichern

## Design-Ziel

Die UI soll sich wie eine luxuriöse Next-Gen-Konsole aus dem Jahr 2035 anfühlen: clean, schnell, dunkel, lebendig und hochwertig – mit Apple-artiger Einfachheit plus futuristischer Gaming-Energie.
